# Nimble — ширма мастера

**Версия: 0.2-alpha** · предварительная сборка · обновлено 2 ноября 2026

Одностраничная офлайн-ширма для ведения игры по **Nimble RPG** на русском языке. Открывается одним HTML-файлом в браузере, без сервера и установки. Данные хранятся в localStorage браузера.

> **Статус: alpha.** Все заявленные функции работают, но возможны ошибки, изменение структуры данных и терминов. Перед игрой делайте экспорт данных (меню «⋯» → «Экспорт всех данных»).

---

## Возможности стола

### Ширма
Сводка на один экран: партия с хитами и ранами, быстрые проверки по четырём атрибутам с выбором сложности, текущий бой, ближайшие напоминания, последние заметки и все состояния с подсказками.

### Персонажи
- Конструктор за три шага: предок, предыстория и класс, массив атрибутов и пункты навыков, броня, оружие и мана.
- Лист персонажа: броски атрибутов и навыков, атаки оружием, хиты, раны, мана, состояния, заметки.
- Безопасный отдых, повышение уровня, удаление и передача героя в бой.
- Классы, кости хитов, спасброски и стартовое снаряжение — из локализации.

### Кубики
- d4, d6, d8, d10, d12, d20, d100 и цифровые d44/d66/d88.
- Произвольные формулы: `2d6+3`, `1d20+5`, `d66`.
- Преимущество и помеха, счётчик костей и модификатор.
- Режим атаки по правилам Nimble: 1 на основной кости — промах, максимум — крит с добросом, крит игнорирует броню.
- История бросков.

### Справочник
461 запись с поиском по названию и тексту и фильтрами по типам:

| Раздел | Записей |
| --- | ---: |
| Правила и термины | 88 |
| Состояния | 17 |
| Оружие | 22 |
| Броня | 20 |
| Снаряжение | 33 |
| Магические предметы | 34 |
| Существа (включая легендарных) | 91 |
| Заклинания (школы, прикладные, тайные) | 95 |
| Классы | 12 |
| Предки | 25 |
| Предыстории | 24 |

Плюс свои записи — текстовые заметки, **свои существа** (уровень, хиты, броня, скорость, действия; добавляются в бой как обычные монстры) и **своё оружие** (кость урона, характеристика, тип, свойства; бросается как атака).

### Печатные карточки
Для монстра или заклинания откройте кнопку «Карточка»: компактная карточка открывается в превью, печатается через «Печатать» (или печать страницы). Подходит для раздачи на стол.

### Трекер боя
- Инициатива, порядок хода, раунды.
- Три действия и реакция на участника, сброс в начале раунда.
- Урон и лечение, реакция «Защита» с вычетом брони, раны, состояния.
- Добавление монстров из бестиария по одному и группами.
- Ручные участники и добавление всей партии.

### Напоминания
- Таймеры с обратным отсчётом и всплывающим уведомлением.
- Эффекты «каждые N раундов»: яд, регенерация, горение.
- Простые чек-листы и быстрые шаблоны.

### Заметки
Редактор с форматированием (жирный, курсив, заголовки, списки, цитаты), автосохранением, поиском, счётчиком слов и выгрузкой в `.md`.

### Данные
- Всё хранится локально, без аккаунтов и сети.
- Экспорт и импорт всех данных в JSON.
- Печать текущего экрана.
- Командный поиск: `⌘K` / `Ctrl+K` или `/`.

## Быстрый старт

1. Скачайте `Nimble-Shirma.html`.
2. Откройте файл в актуальном Chrome, Safari или Firefox.
3. Создайте героя или начните бой с монстрами из бестиария.
4. Делайте экспорт данных перед важной игрой.

Ничего не устанавливается, интернет не нужен.

## Ограничения предварительной сборки

- Данные привязаны к браузеру и профилю: очистка кэша или режим инкогнито их удалят. Синхронизации между устройствами нет.
- Уведомления напоминаний работают, пока вкладка открыта; фоновых push-уведомлений нет.
- Правила и тексты — фанатский перевод и конспект для стола, а не замена книге. В спорных случаях приоритет у книги правил.
- Возможны расхождения в терминах между разделами локализации.
- Мобильная вёрстка базовая: всё доступно, но стол рассчитан на экран от 1280 px.

## Структура репозитория

```text
Nimble-Shirma.html        готовая офлайн-ширма (открывать этот файл)
nimble-shirma/            исходники
  index.html              оболочка
  styles.css              оформление
  app-*.js                логика: ширма, персонажи, кубики, справочник, бой, заметки
  data-ru.js              справочник из локализации Nimble Vault RU
  tools/build-data.py     генератор data-ru.js
  tools/verify-actions.json  сценарий браузерной проверки
  README.md               технические заметки по сборке
```

## Сборка и проверка

```text
multitool-node --skill websites site.cjs bundle nimble-shirma/index.html Nimble-Shirma.html
multitool-node --skill websites site.cjs check Nimble-Shirma.html
multitool-node --skill websites verify.cjs Nimble-Shirma.html --actions nimble-shirma/tools/verify-actions.json
```

Обновление данных из локализации:

```text
python3 nimble-shirma/tools/build-data.py
```
